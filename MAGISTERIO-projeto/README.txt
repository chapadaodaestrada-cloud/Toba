MAGISTÉRIO — PROTÓTIPO VISUAL

Estrutura:
- index.html: página principal e estrutura do site
- css/style.css: estilos e layout
- js/script.js: navegação e interações demonstrativas
- assets/: pasta reservada para imagens e outros recursos

Como executar:
1. Extraia o arquivo ZIP.
2. Abra a pasta MAGISTERIO-projeto.
3. Dê dois cliques em index.html para abrir no navegador.

Observações:
- O projeto funciona localmente, sem instalação de dependências.
- O login é demonstrativo: aceita qualquer nome e senha preenchidos.
- Não use senhas reais.
- Benefícios, valores, notificações e solicitações são fictícios.
- Este protótipo não tem vínculo com órgãos públicos e não consulta benefícios reais.
